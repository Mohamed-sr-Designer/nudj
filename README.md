# نُضْج — NUDJ

ملحمة إلكترونية سعودية: ذبائح وقطعيات ضأن وبقر ومفروم وبوكسات، تُقطّع وتُغلّف حسب طبخة العميل.
ومعها **«الخبرة»**: خدمة إضافية اختيارية مدفوعة (أدلة مصوّرة، مختبر الطبخ، استشارة جزّار).

- **الموقع:** https://mohamed-sr-designer.github.io/nudj/
- على الشاشات الكبيرة: موقع ويب كامل. تحت 900px: تجربة تطبيق بنمط iOS (شريط تبويبات، عنوان كبير ينكمش، أوراق سفلية، شريط إجراء ثابت).
- يمكن تثبيته على الشاشة الرئيسية كتطبيق (PWA).

## نموذج العمل

| | مجاناً | دليل واحد (9 ر.س) | نُضْج+ (29 ر.س/شهر · 249 ر.س/سنة) |
|---|---|---|---|
| المتجر كاملاً + خيارات الوزن والتقطيع | ✓ | ✓ | ✓ |
| مخطط الذبيحة والمعلومات الأساسية لكل قطعة | ✓ | ✓ | ✓ |
| «وش تطبخ»: القطعيات المناسبة + حاسبة الكمية | ✓ | ✓ | ✓ |
| فيديو التقطيع + خطوات الطبخ والحرارات | — | لقطعة واحدة | الكل |
| خطوات الطبخات بالتفصيل | — | لطبخة واحدة | الكل |
| مختبر الطبخ (مرجع النضج والأخطاء) | — | — | ✓ |
| استشارة جزّار (20 دقيقة) | 49 ر.س | 49 ر.س | 25 ر.س |

الخبرة تُعرض في لحظات الحاجة فقط، ولا تمنع أي عملية شراء:
خيار «أضف الدليل» داخل نموذج الشراء ← شريحة «+ أضف الدليل» في السلة ← صفحة الدليل (شراء فوري) ← صفحة الخبرة (الاشتراك).

## التعديل

كل شيء في ملف واحد: **`assets/js/data.js`**

| ماذا | أين |
|---|---|
| الأسعار، رسوم التوصيل، سعر الدليل والاشتراك والاستشارة، المدن، فترات التوصيل، طرق الدفع، أكواد الخصم | `CONFIG` |
| بيانات التواصل والسجل التجاري (مكتوبة الآن بين [أقواس]) | `CONFIG.contact` |
| المنتجات والخيارات ومحتوى الأدلة المدفوعة | `PRODUCTS` |
| الأطباق وخطواتها | `DISHES` |

بعد أي تعديل: `node build.js` (يولّد كل الصفحات وsitemap وllms.txt).

### إضافة الصور
1. ضع الصورة في `assets/img/`.
2. **صور المنتجات:** في المنتج داخل `PRODUCTS` أضف `img: "assets/img/lamb-rack.jpg"` وللمعرض `gallery: ["...", "..."]` (مربّعة 1:1).
3. **صور الصفحات** (البانر، الأنواع، الخبرة، الاستشارة، من نحن): في `IMAGES` — المقاس المقترح مكتوب بجانب كل خانة.
4. `node build.js`. أي خانة بلا صورة تبقى مستطيلاً رمادياً.

### إضافة الفيديو
- دليل قطعة: `video: "https://..."` داخل المنتج (رابط mp4 أو رابط تضمين YouTube/Vimeo).
- دليل الطبخة: `video` داخل الطبخة في `DISHES`.
- دليل الذبيحة: `CARCASS_GUIDE.video`.

## التشغيل محلياً
```
node build.js
node serve.js   # http://localhost:4774
```

## البنية
- `src/shell.js` الإطار المشترك (ترويسة الموقع + شريط التطبيق + التبويبات + الفوتر)
- `src/pages/*.js` قوالب الصفحات — صفحة ثابتة لكل منتج (`lamb-rack.html`) ولكل دليل (`guide-lamb-rack.html`) ولكل طبخة (`dish-kabsa.html`)
- `assets/js/store.js` الحالة (السلة، الحساب، الاشتراك، الطلبات…)
- `assets/js/app.js` سلوك الواجهة المشترك · `assets/js/pages/*.js` منطق كل صفحة

## ما هو محاكى حالياً (يحتاج خادماً عند الإطلاق)
`CONFIG.demo = true` يُظهر تنبيهاً واضحاً في كل خطوة دفع.
- **الدفع:** واجهة كاملة بلا بوابة دفع — يحتاج ربطاً (مثل Moyasar أو HyperPay أو Tap) وفوترة اشتراكات متكررة.
- **رمز التحقق:** يقبل أي 4 أرقام — يحتاج خدمة SMS.
- **الحساب والطلبات والاشتراك:** محفوظة في المتصفح (localStorage) — تحتاج قاعدة بيانات. طبقة `store.js` مصمّمة لتُستبدل بواجهة برمجية دون تغيير بقية الموقع.
- **حماية المحتوى المدفوع:** الأدلة تُفتح في الواجهة فقط — في الإنتاج يجب أن يرسل الخادم المحتوى والفيديو لمن يملك الحق فقط.
- كود الخصم التجريبي: `NUDJ10` (10٪ على اللحوم).
