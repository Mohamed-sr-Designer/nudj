# نُضْج — NUDJ

ملحمة إلكترونية سعودية **ومستشار طبخ تفاعلي**: قل للمستشار وش المناسبة، ويحسب لك القطعيات بالجرام، التقطيع، التتبيلة، الفحم والبهارات — وتطلب الخطة كاملة بضغطة.

- **الموقع:** https://mohamed-sr-designer.github.io/nudj/ — **English:** https://mohamed-sr-designer.github.io/nudj/en/
- على الشاشات الكبيرة: موقع كامل. تحت 900px: تجربة تطبيق بنمط iOS (شريط تبويبات وزر المستشار في المنتصف، عنوان كبير ينكمش، أوراق سفلية، شريط إجراء ثابت). يُثبَّت كتطبيق (PWA).
- الهوية «Butcher Noir»: أردواز داكن + ورق جزّار كريمي + جمرة برتقالية. الشعار «نضج» بالكوفي المربّع يقطعه خط سكين (`assets/brand/`).

## القطيع (6 مواشي · 40 قطعية · 5 ذبائح · 7 إضافات)
ضأن · ماعز · حاشي · عجل · بقر · جاموس. لكل ماشية صفحة (`lamb.html` …) فيها رسمها الخطي بنقاط مرقّمة لكل قطعة (`ANIMALS[].pins`).

## المستشار (`assets/js/advisor.js`)
محادثة بحلقة مفتوحة: المناسبة ← العدد ← الشكل (قطع/شرائح/قطع سليمة/كباب/كبدة) ← الماشية ← التتبيل ← التسييخ ← العدّة ← **فاتورة بالجرام**.
- مناسبات: حفلة مشاوي، عزومة/وليمة، ذبيحة كاملة، عشاء ستيك، طبخ الأسبوع، سؤال عن قطعة.
- كل إجابة قابلة للتعديل بالضغط عليها، والأوزان تُعدّل بـ − و + داخل الفاتورة.
- بعد النتيجة: أضف للسلة · عدّل العدد · أضف مناسبة ثانية (تتجمّع في خطة واحدة) · احفظ الخطة · ابدأ من جديد.
- يفهم الكتابة البسيطة: «كبسة حاشي لـ 12» أو «مشاوي لـ 8 أشخاص ضأن».
- يظهر: مضمّناً في الرئيسية، صفحة كاملة (`advisor.html` والتبويب الأوسط)، زر عائم يفتح درجاً، «كم تحتاج؟» في صفحة المنتج يضبط الميزان، وملاحظات في السلة (فحم، أسياخ، بهارات، تتبيل).
- القواعد (جرامات الشخص، الفحم، الأسياخ، البهارات) في `ADVISOR` داخل `data.js`.

## النسخة الإنجليزية (`/en/`)
كل صفحة لها نسخة إنجليزية بنفس الاسم داخل `en/` (من اليسار لليمين)، وزر **EN / ع** في الترويسة وشريط التطبيق والفوتر ينقلك لنفس الصفحة باللغة الثانية.
- نصوص البيانات بالإنجليزي في **`assets/js/en.js`**: تضيف لكل نص عربي نسخة `_en` بجانبه (`name` ← `name_en`). الأسعار والصور والإعدادات مشتركة.
- نصوص الواجهة داخل الكود بصيغة `L("عربي", "English")`.
- الطلبات والسلة والعناوين مشتركة بين اللغتين (المدن ونوع العنوان تُحفظ بالعربي وتُعرض بلغة الصفحة).
- في لوحة التحكم: زر **عربي / English** أعلى الصفحة يبدّل الحقول لتعديل النسخة الإنجليزية (النص العربي يظهر كتلميح).
- المستشار يفهم الكتابة بالإنجليزي أيضاً: «bbq for 8 lamb» أو «camel kabsa for 12».

## لوحة التحكم (`admin.html`)
الرابط: `/admin.html` (ومؤقتاً رابط «لوحة التحكم» في الفوتر) — رمز الدخول الافتراضي **`2026`** (يُغيَّر من «الدفع والتوصيل ← رمز لوحة التحكم»).

كل قسم في الموقع يُعدَّل منها:
| القسم | ما يُعدَّل |
|---|---|
| الطلبات | كل الطلبات وحالتها (تم الطلب ← في التقطيع ← في الطريق ← تم التسليم / ملغي)، حذف الطلب |
| المنتجات | السعر، الاسم، الوصف، الصور، الأوزان، الأشكال، إخفاء/إظهار، منتج جديد، حذف |
| القطيع | بيانات كل ماشية، رسمها الخطي، **سحب النقاط على الرسم**، ماشية جديدة |
| الخدمات | التتبيلات وأسعارها، أشكال التقطيع، التسييخ، التغليف |
| المستشار | جرامات الشخص، نسب الفحم والأسياخ، المناسبات، أشكال الشوي، الأطباق، نص كل سؤال |
| الرئيسية | ترتيب الأقسام العشرة وإظهارها/إخفاؤها |
| النصوص | كل عنوان ونص في كل صفحة (الترويسة، الشريط، الفوتر، كل الصفحات) — تدعم `{fee}` `{phone}` `{cities}`… |
| الأسئلة | الأسئلة الشائعة ومركز المساعدة |
| الصور | استبدال أي صورة بالرفع أو الرابط |
| الدفع والتوصيل | طرق الدفع وشعاراتها، الرسوم، الحد المجاني، الضريبة، المدن، الأوقات، الكوبونات، بيانات التواصل، **مراحل الطلب الأربع** (اسمها ووصفها وأيقونتها) |
| الهوية | لون الجمرة (اللون الأساسي) |

**طريقة الحفظ:** التعديلات تُحفظ تلقائياً كمسودة في المتصفح ← «معاينة» تعرض الموقع بالمسودة ← «نشر» يرفع الصور إلى `assets/img/uploads/` ويكتب `assets/js/content.js` في المستودع عبر GitHub (يحتاج Fine-grained token بصلاحية Contents: Read & write على مستودع `nudj` فقط). بعد النشر بدقيقة يظهر التعديل للجميع. بديل بدون توكن: «تنزيل content.js» ثم ضعه في `assets/js/` وارفعه.

بعد أي نشر، تشغيل `node build.js` محلياً يدمج المحتوى داخل الصفحات الثابتة (أفضل لمحركات البحث). بدونه يعيد المتصفح بناء الصفحة من `assets/js/templates.js` تلقائياً.

> **تنبيه:** الرمز حماية شكلية في المتصفح فقط، والطلبات في النسخة التجريبية محفوظة في متصفح العميل (اللوحة ترى طلبات نفس الجهاز). الإطلاق الحقيقي يحتاج خادماً وقاعدة بيانات ودخولاً آمناً.

## التعديل من الكود
الافتراضيات في **`assets/js/data.js`**: الإعدادات، القطيع، المنتجات والأسعار، التتبيل والخدمات، قواعد المستشار، النصوص (`COPY`)، أقسام الرئيسية (`HOME`)، مراحل الطلب (`ORDER_STEPS`)، طرق الدفع (`CONFIG.payments`). ما تنشره اللوحة في `content.js` يطغى عليها. بعد أي تعديل: `node build.js`.

### الصور — بالاسم فقط
| النوع | المجلد | الاسم |
|---|---|---|
| صور الصفحات | `assets/img/site/` | `home-hero` · `occ-grill` · `occ-feast` · `occ-carcass` · `occ-steak` · `occ-weekly` · `marinade` · `texture` · `about` · `og-share` |
| صور المنتجات | `assets/img/products/` | `<id>-1` (الرئيسية) · `<id>-2` · `<id>-3` (المعرض) — مثال: `lamb-rack-1.webp` |
| رسومات المواشي | `assets/img/herd/` | `lamb.png` · `goat.png` · `camel.png` · `veal.png` · `beef.png` · `buffalo.png` |
| شعارات الدفع | `assets/img/pay/` | `applepay` · `mada` · `visa` · `mastercard` · `tamara` (png) |
| ما يُرفع من اللوحة | `assets/img/uploads/` | اسم تلقائي |

يُقبل jpg/png/webp. الصور الحالية مولّدة بـ Magnific (Nano Banana Pro) بنفس أسلوب صورة البطل.

## التشغيل محلياً
```
node build.js
node serve.js   # http://localhost:4774
```

## البنية
- `src/shell.js` الإطار (ترويسة + شريط التطبيق + التبويبات + الفوتر) · `src/pages/*.js` قوالب الصفحات (صفحة ثابتة لكل منتج وماشية)
- `assets/js/store.js` الحالة (السلة بالوزن والخدمات، الطلبات، خطط المستشار…) · `ui.js` دوال العرض (بطاقة الجزّار، الفاتورة، الميزان…) · `app.js` سلوك الواجهة · `advisor.js` المستشار · `pages/*.js` منطق كل صفحة
- `assets/js/cms.js` يطبّق المحتوى المنشور (`content.js`) أو مسودة المعاينة · `templates.js` (مولّد) نسخة المتصفح من القوالب لإعادة البناء · `pages/admin.js` لوحة التحكم
- الروابط القديمة (أدلة، أطباق، اشتراك) تُحوَّل تلقائياً من `404.html` وصفحات التحويل.

## ما هو محاكى حالياً
`CONFIG.demo = true`: الدفع ورمز التحقق محاكاة، والحساب والطلبات محفوظة في المتصفح (localStorage). تحتاج بوابة دفع وخدمة SMS وقاعدة بيانات عند الإطلاق. الأسعار مقترحة. البيانات بين [أقواس] تُستبدل.

فكرة «الخبرة» السابقة (أدلة فيديو واشتراك نُضْج+) محفوظة كمسودة في مجلد `فكرة جديدة/` (خارج المستودع).
