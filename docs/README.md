# NUDJ — Walkthrough deck + UX journey

## `presentation/`
| File | What it is |
|---|---|
| `NUDJ-Website-Walkthrough.pptx` | 33 slides in simple English: user flow → every feature → admin dashboard. Editable, with speaker notes on every slide. |
| `NUDJ-Website-Walkthrough.pdf` | The same deck, pixel-exact, fonts embedded. Use this offline copy to present from any device. |

**Open in Google Slides:** drive.google.com → New → File upload → pick the `.pptx` → right-click → Open with → Google Slides.
**Open in Figma Slides:** Figma → Drafts → Import → pick the `.pptx`. Figma turns it into a Slides deck.

Fonts are Google Fonts: **Alexandria**, **IBM Plex Sans**, **IBM Plex Mono**. Google Slides and Figma both support them. For PowerPoint or Keynote, install them first or text falls back to a default font.

## `ux-journey/`
| File | What it is |
|---|---|
| `01-ux-journey-map.svg` | UX journey map: persona (Khalid), 7 stages × doing / thinking / feeling / pain points / how NUDJ answers / opportunities / dashboard metric, plus real screens. |
| `02-user-flow.svg` | User flow: advisor path, browse path, buy and come back, and the store-team dashboard lane, with the links between them. |
| `*.pdf` / `*.png` | Vector PDF and PNG previews of the same two boards. |

**Into Figma:** drag the two `.svg` files onto a Figma design canvas. Text comes in as editable text layers, and screens come in as images.

Screens were captured from the live demo (English site, 1600 px desktop and 390 px phone). The dashboard uses clearly labelled demo data.
